# PressGarden 0.1.0

WordPress maintenance and performance management.

## Initial independent release

Native database check/engine-aware repair/optimization/cleanup, preview-first disposable-file cleanup, LiteSpeed cache operations and all eight advanced LiteSpeed CLI command families now have their own standalone tool. No PressWarden installation is required.

Database changes retain private SQL backups and measurable output. Unsupported storage-engine repair is not reported as corruption. LiteSpeed before/after verification does not claim full optimization when nonzero counters remain; regenerated transients can produce `UNVERIFIED` and exit 2 even after cleanup commands complete.

## Primary commands

```bash
pressgarden db check example.com
pressgarden cache status example.com
pressgarden litespeed-db status example.com
pressgarden litespeed-db optimize example.com
```

Optimization changes databases. Review backup/recovery procedures and confirmation prompts before execution. Configured cache state is not a proven HTTP cache hit, and allocation changes are not guaranteed disk-space reclamation.

## Verification and downloads

This release is published only after all required main-branch workflows pass for the exact source commit. `SOURCE.json` records the commit, Git tree and passing workflow-run links. `SHA256SUMS` covers the tracked-source archive, source manifest and these notes. No local work files, credentials or client data are included.

The initial split included isolated WordPress/MySQL integration, PHP 7.4 compatibility, fixture/lifecycle tests and downloaded-installer regressions. Consult the recorded CI evidence for the released commit rather than assuming all hosting environments were tested.

Publication does not install anything on client servers or modify websites, databases or scheduled tasks. Effective web PHP settings, actual HTTP cache/CDN behavior, credentialed external services and a database restore/recovery drill remain staging checks. A checksum-verified backup is not a tested restore.
